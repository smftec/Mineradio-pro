# Mineradio pro 开发计划

## Context

用户要求参考 [oirge/Mineradio](https://github.com/oirge/Mineradio)(一个基于 Electron 的本地音乐播放器,817 commits)全新开发一个 Windows 应用 **Mineradio pro**,在原版功能基础上增加**软件检测和更新**能力。

已确认决策:
- **技术栈**:Electron(与原版一致,桌面歌词/迷你播放器/全局快捷键/自动更新方案成熟)
- **更新方式**:electron-updater + GitHub Releases(支持设置中自定义更新源 URL 以便走国内镜像)
- **首版范围**:核心完整版(Folia 唱片墙等高级视觉功能留待后续版本)

工作目录 `T:\2、win\11-mineradio` 为空,项目直接建在该目录下。渲染进程用原生 ES Modules(不用 webpack/vue),`npm start` 即可运行,与原版轻量风格一致。

## 项目结构

```
T:\2、win\11-mineradio\
├── package.json              # build.publish 指向 GitHub(占位 owner/repo,可改)
├── build\icon.ico            # 生成的应用图标
├── desktop\                  # 主进程(ESM)
│   ├── main.js               # 入口:窗口管理(主窗/迷你/桌面歌词)、IPC 路由、自定义协议
│   ├── preload.js            # contextBridge 暴露安全 API
│   └── lib\
│       ├── config.js         # 设置持久化(userData/config.json,自写 ~80 行)
│       ├── library.js        # 曲库:递归扫描 + chokidar 监控增量同步 + 分类索引
│       ├── metadata.js       # music-metadata 解析标签/封面;封面缓存到 userData/covers
│       ├── lyrics.js         # 歌词:.lrc(含逐字 [mm:ss.xx])+ 内嵌 USLT/SYLT/Vorbis;
│       │                     #   chardet+iconv-lite 多编码识别(UTF-8/16, GB18030, Big5, Shift_JIS)
│       ├── playlists.js      # 歌单 CRUD
│       ├── stats.js          # 播放统计 + 断点续播
│       └── updater.js        # electron-updater:静默检查/手动检查/下载进度/安装,
│                             #   设置中自定义 feed URL 时用 setFeedURL({provider:'generic'})
└── public\                   # 渲染进程
    ├── index.html            # 主窗口
    ├── mini.html             # 迷你播放器窗口
    ├── lyrics.html           # 桌面歌词窗口
    ├── css\{app,mini,lyrics}.css
    └── js\{app,player,views,lyrics-view,components}.js
```

## 功能模块(核心完整版)

1. **曲库**:导入文件夹/文件 → 递归扫描(支持 mp3/flac/wav/ogg/opus/m4a/aac/webm)→ 存 JSON 索引;chokidar 监控新增/删除/修改自动同步;分类视图(歌曲/艺术家/专辑/流派/最近添加/最近播放/播放最多);搜索框过滤
2. **播放引擎**:单 `<audio>` + Web Audio API;播放队列、随机/单曲/列表循环;0~10s 交叉淡入淡出(双 audio 元素交叉);断点续播;音量记忆
3. **均衡器**:10 段 EQ(BiquadFilter 链)+ 预增益 + 几个音效预设(平直/流行/摇滚/古典/低音增强),Web Audio 实现
4. **歌词**:解析后传渲染进程;主窗口歌词视图(逐字高亮、随进度滚动);**桌面歌词**独立透明置顶窗(可拖动/锁定/双行显示)
5. **迷你播放器**:独立无边框小窗,封面+控制,可切回主窗口
6. **播放统计**:次数/累计时长/最近播放;最近播放记录清空
7. **设置页**:主题(深/浅)、音频输出设备、EQ、快捷键映射(应用内)、更新设置、关于(当前版本号)
8. **⭐ 软件检测和更新**(核心新增):
   - 启动后延迟静默检查(可关);设置页"检查更新"按钮
   - 状态流转:检查中 → 有新版本(版本号+更新日志)→ 下载进度条 → "重启并安装"
   - 更新源:默认读 package.json 的 `build.publish`(GitHub,owner/repo 为占位符 `your-name/Mineradio-pro`,交付时在 README 说明如何改);设置中可填自定义 URL 切换 generic provider
   - dev 模式下检查更新给出友好提示(打包后才生效)

## 关键实现要点

- **安全**:contextIsolation:true、nodeIntegration:false、sandbox:false(渲染需 audio 本地流)、CSP meta
- **音频流**:注册自定义协议 `minerdio-pro://` 流式读本地文件,给 `<audio>`(避免 file:// 限制)
- **窗口**:主窗 frame:false 自定义标题栏;桌面歌词窗 `alwaysOnTop('screen-saver')`+transparent+`setIgnoreMouseEvents` 锁定切换
- **依赖**:运行时 `electron-updater ^6`、`music-metadata ^11`、`chokidar ^4`、`iconv-lite`、`chardet`;开发时 `electron ^43`、`electron-builder ^26`、`png-to-ico`(图标转换)
- **图标**:用图片生成工具生成 1024×1024 PNG(深色玻璃质感 + 音符/矿石元素)→ png-to-ico 转 ico
- **打包**:electron-builder → NSIS 安装包(非一键、按用户安装、桌面/开始菜单快捷方式),产物 `dist/Mineradio-pro-Setup-x64.exe`
- **npm 镜像**:若 Electron 二进制下载慢,设置 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`

## 实施顺序

1. 脚手架:package.json、主/渲染进程骨架、图标、窗口能启动
2. 主进程 lib 模块:config → library → metadata → lyrics → playlists → stats
3. 渲染进程:布局/导航/曲库列表 → 播放条+引擎 → 分类视图 → EQ 设置
4. 歌词视图 + 桌面歌词窗口 + 迷你播放器
5. updater 模块 + 设置页更新 UI
6. `npm run build:win` 打包验证 + README(含发布/更新流程说明)

## 验证

1. `npm start` 启动,截图核对主界面/播放/歌词/迷你播放器/桌面歌词
2. 用本机音乐文件夹实测:扫描、播放、歌词、统计
3. dev 下验证更新 UI 状态流转(提示打包后生效);检查 `npm run build:win` 产出安装包
4. 交付时说明:如何把占位 repo 改为自己的 GitHub 仓库、发版后自动更新如何工作
